
# SkillSync 🚀

SkillSync is a full-stack job application and skill management platform built to help students track job applications, manage technical skills, and organize interview schedules in one place.

## Features

- User registration and login
- JWT-based authentication
- Track job applications
- Manage technical skills and proficiency levels
- Schedule and manage interviews
- Dashboard with application statistics
- Profile management
- Search and filter job applications
- User-specific data isolation
- Responsive user interface

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- Vite

### Backend
- Python
- Django
- Django REST Framework
- Simple JWT

### Database
- PostgreSQL
